# MJJsteamtools 动效根基

动效只解释状态与空间关系，不让主要任务等待。代码统一入口为 `Controls/AppMotion.cs`（时长/曲线）与 `Controls/MotionBehavior.cs`（附加行为/组合变换）。

## 节奏与优先级

| 节奏 | 时长 | 使用场景 |
| --- | ---: | --- |
| Press | 85 ms | 按压预备、按钮微挤压 |
| Feedback | 155 ms | 悬浮与字段状态变化 |
| Settle | 190 ms | 松开后的轻微回弹 |
| Content | 230 ms | 局部内容显示、侧栏开合 |
| Page | 260 ms | 详情页进入及主要视图切换 |
| Exit | 140 ms | 详情页退出 |

进入用 ease-out，退出用 ease-in，侧栏位移用 ease-in-out。松开按钮才使用幅度为 0.18 的 BackEase；普通列表不弹跳。首屏列表只给前 6 项安排最多 4 级、每级 28 ms 的错峰，其余项立即显示，以免大量卡片同时动画。

## 迪士尼十二原则的产品化映射

| 原则 | 在本应用中的做法 |
| --- | --- |
| 挤压与拉伸 | 按压按钮时 X 轴约 1.012 / Y 轴约 0.978；主要按钮略强。 |
| 预备动作 | 按压阶段先收紧，松开才完成动作反馈。 |
| 演出布局 | 详情页主体与指标条先后进入，主要按钮和当前状态始终优先可见。 |
| 逐帧与关键姿态 | 交互只用确定的开始、目标与完成姿态，不用随机运动。 |
| 跟随与交叠 | 松开后的短暂回弹、主体与指标条的 28 ms 交叠。 |
| 慢入慢出 | 统一的进入、退出和双向缓动语义。 |
| 弧线运动 | 详情页进入使用轻微 X/Y 弧线，而非长距离直线飞入。 |
| 次要动作 | 卡片微抬升和侧栏选中条只衬托主导航。 |
| 时间掌控 | 85–260 ms 的任务分级，退出快于进入。 |
| 夸张 | 仅主要按钮比普通按钮有稍强的按压反馈，避免全屏弹跳。 |
| 扎实造型 | 在组合 RenderTransform 上动画，不改布局尺寸；中心锚点保持稳定。 |
| 吸引力 | 统一的克制幅度、方向和节奏服务于内容清晰度。 |

## 应用范围

- 全局主/次按钮：悬浮、按下、松开与复位；主要按钮通过 `IsEmphasisEnabled` 表达层级。
- 游戏库卡片：已有的抬升行为沿用统一时间曲线；加载时只有前 6 项错峰进入。
- 游戏详情：页面弧线进入、快速退出；概览与指标条分层进入。快速开关不会被上一轮退出回调覆盖。
- 设置页、游戏修改器、存档保险箱：局部内容统一使用同一进入行为。
- 侧栏：开合、图标对齐和选中指示器使用统一的 Content 时长与双向曲线。
- 账号弹层：短距离进入、快速退出；重新打开会取消旧的延迟关闭。

## 可访问性与性能

当 Windows 关闭客户端区域动画（`SystemParameters.ClientAreaAnimation == false`），行为直接写入最终姿态、退出等待为零。动画只改透明度和变换，不改卡片宽高；长列表限制同步入场数量。不要把装饰性无限循环动效加入列表、加载结果或按钮。

不对整个主窗口做入场透明度动画：那会让子控件在自动化树里暂时不可见，也会让窗口启动看起来像空白。入场只施加在可理解的内容层级。

新增视图应优先复用 `MotionBehavior.PlayEntrance/PlayExit` 或现有附加属性。只为显著状态变化添加动作；不要再次定义局部 180/220 ms 曲线，也不要覆盖已有 RenderTransform。
